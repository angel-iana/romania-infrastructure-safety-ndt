# Date

Datele **nu** urcă pe GitHub. Se regenerează rulând scripturile din `extragere/`.

- `date/brut/` – fișierele exact cum au fost descărcate, cu data în nume (ex. `bilanturi_2024_2026-10-08.csv`).
- `date/procesat/` – fișiere intermediare (ex. tabele extrase din PDF).
- `*.duckdb` – baza de date locală.
