# Fișe surse

Fiecare sursă de date are o fișă care descrie ce conține, cum se accesează și ce limitări are.
Șablonul este în `_sablon-fisa-sursa.md`. Fișele sunt numerotate: `01-bilanturi-mf.md`, `02-sicap-istoric.md` etc.

`surse_cercetare.csv` – catalogul complet al surselor identificate, generat cu promptul din `prompts/cercetare-surse.json`.
